# 3단계 · 벤치마크

**이 단계를 건너뛰면 리포트가 성립하지 않는다.** 대상 채널 숫자만으로는 "나쁘다"를
말할 수 없다. 비교군이 있어야 "이 채널만 그렇다"가 된다.

## 3.1 후보 수집과 선정

유튜브 검색 질의 20~40개로 후보를 모은 뒤 **체급과 카테고리로 거른다.**

선정 조건(원 사례):
- 같은 카테고리 (여성의류 중심)
- 같은 송출 구조 (유튜브 라이브 + 외부 결제 페이지)
- 같은 체급 (구독 1.7만 이상 — 대상 채널 2.4만의 ±로 잡음)

**6곳 안팎이면 충분하다.** 더 늘려도 결론은 안 바뀌고 수집 비용만 는다.

체급이 안 맞는 채널은 넣지 않는다. 구독 50만 채널과 비교하면 셀러가 즉시
"체급이 다르잖아요"로 반박하고, 그 순간 리포트 전체의 신뢰가 깎인다.

## 3.2 같은 파이프라인을 돌린다

각 채널 최근 8회차에 **1·2단계를 그대로** 적용한다. 채팅 리플레이 전량 재생,
10분 버킷 집계, 동일 `INTENT_RE` 정규식.

**공정 비교를 위한 필수 보정:** 대상 채널의 주문봇 메시지는 벤치마크 비교 시
**제외하고 다시 센다.** 상대 채널엔 봇이 없으므로 그대로 두면 대상 채널만 채팅 수가
부풀려진다.

레퍼런스 채널은 대개 주문 로그를 남기지 않는다 → **전환율 비교는 불가능**하고
구매의사 발화(`intent_per_1k`)까지만 비교된다. 이 한계를 표 각주에 적는다.

## 3.3 등급을 매긴다 — "잘 나온 회차"가 아니라 "따라 할 채널인가"

단순 순위표를 만들지 않는다. 각 채널을 역할로 분류한다.

| 등급 | 뜻 | 리포트에서의 쓸모 |
|---|---|---|
| **1순위** | 체급이 같은데 지표가 확연히 낫다 | 목표선. 단 **상한**이지 달성 목표가 아님을 명시 |
| **2순위** | 특정 지표에서 배울 점이 있다 | 보조 근거 |
| **참고** | 규모는 롤모델이나 전환 효율은 아님 | 규모≠효율을 보여줌 |
| **대조군** | 대상 채널과 같은 문제를 겪는 동료 | "혼자만의 문제가 아니다" — 셀러 방어감 완화 |
| **반면교사** | 조건이 더 좋은데 지표가 나쁘다 | **가장 중요.** 아래 참조 |

### 반면교사가 결론을 만든다

원 사례의 두 채널:
- **조회수 1.9배 + 홉 더 짧음 + 응대율 더 높음 → 그런데 참여 최하위**
- **가장 짧은 방송(166분) → 그런데 죽은 구간 51%, 구매의사 최하위**

여기서 나오는 결론: **조회수 확대·홉 단축·길이 단축 어느 하나만으로도 해결되지 않는다.**
그래서 처방을 순서대로 묶어 실행해야 한다 — 단독 처방을 파는 경쟁사 제안과 갈리는 지점이다.

### 1순위 채널의 모순도 적는다

원 사례 1순위 채널은 **진행자 채팅이 0건**인데 참여가 끝까지 유지됐다. 즉 "응대만으로는
격차가 설명되지 않는다". 이걸 숨기면 정직하지 않고, 적으면 리포트가 더 믿을 만해진다.
**자기 처방에 불리한 데이터를 먼저 꺼내는 것**이 이 리포트 형식의 신뢰 장치다.
