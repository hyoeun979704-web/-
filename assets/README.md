# assets/

Place image assets here:

- `og-image.jpg` — 1200×630 share/preview image (KakaoTalk, Open Graph).
- Gallery & hero photos — referenced from `css/style.css` (`.hero__photo`) and
  generated in `js/main.js` (gallery tiles). Until real photos are added, the
  page renders soft gradient placeholders so the layout is fully previewable.
